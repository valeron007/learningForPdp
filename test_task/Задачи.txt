2. Задача за знание MySQL.
В Bitrix есть инфоблоки товар и торговое предложение, связанные в соотношении "один ко многим". У товаров есть свойство:
Артикул, код = ARTICLE.
У торгового предложения есть свойства:
Элемент каталога, код = CML2_LINK (указатель на товар)
Размер, код = SIZE (свойство типа enum, выбирается из списка вариантов)
Названия таблиц и столбцов - стандартные для Bitrix.
Задача: написать SQL-запрос, который выбирает все артикулы товаров, у которых есть торгое предложение с размером "L".
На выходе: файл с расширением sql, в котором только запрос, начинающийся с оператора SELECT
